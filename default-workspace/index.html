    HOW IT WORKS

    把一张完整的图，
    倒着讲一遍。

    导入已经画完的机械图样，软件会拆解图元、识别线型与图层，排出一道可播放的“制图工序”。

    01导入矢量图

    支持 ASCII DXF 与 SVG。DXF 会重建直线、圆、圆弧、多段线、文字和常见尺寸标注。

    02自动排工序

    中心线先行，再画轮廓、虚线、剖面线，最后标注尺寸、写文字、补图框。

    03逐笔播放

    笔尖沿图线移动，可暂停、拖动进度、单步跳转，也可以切换工程图黑白配色。

    让自动识别更准确

    • DXF 图层名包含 CENTER / 中心线、HIDDEN / 虚线、DIM / 标注，可被准确归入对应工序。
    • SVG 建议保留分组名称（如 中心线、轮廓、尺寸），线型保留为虚线或点划线。
    • 支持模型空间中的常见二维图元；图片、光栅填充、部分动态块与三维对象不会参与演示。

    快捷键

    空格 播放 / 暂停 ←→ 上一道 / 下一道工序 R 重播 F 适应窗口 G 网格 Esc 关闭对话框

    这是一个教学与演示工具，不是 CAD 编辑器。它从“完成图”反推过程，因此自动排序是启发式的；你可以把图层命名得更规范，得到更接近真实制图习惯的工序。
